# NUFORC Detail Extractor

Reads hyperlinks from an Excel workbook and extracts detail-page fields from NUFORC sighting pages.

## Requirements

pip install -r requirements.txt

## Output Fields

- Occurred Detail
- Reported Detail
- Duration Detail
- No of observers
- Location Detail
- Location details
- Shape Detail
- Color
- Estimated Size
- Viewed From
- Direction from Viewer
- Angle of Elevation
- Heading
- Closest Distance
- Estimated Speed
- Characteristics
- Description
- Posted
